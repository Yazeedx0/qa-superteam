# Returns

You can return an item within 30 days of purchase as long as it is unused and in its original packaging.
Start a return from the Orders page in your account and print the prepaid return label.
Return labels are free for exchanges; for other returns a $6 label fee is deducted from your refund.
Drop the package at any UPS location within 7 days of printing the label.
Once the item reaches our warehouse, we inspect it within 3 business days.
