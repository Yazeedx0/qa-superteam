# Comparing a contract between two git refs

The question is always "what does a consumer built against BASE experience when it talks
to HEAD?". Get both documents as files under `.qa-superteam/contracts/` (inside the
git-ignored output directory), diff them with a real tool, record the diff as an
execution, then classify with `breaking-change-catalogue.md`.

## 1. Find the base

- Review/PR runs: the run's `--base` ref (`qast run status`), or `qast impact --base <ref>`
  which also lists changed contract files.
- Release checks: the tag of the last release (`git describe --tags --abbrev=0`).
- No git history: ask for the previous spec or a published copy; otherwise the
  compatibility question is BLOCKED (say so) and only implementation-vs-spec testing
  remains.

## 2. Get both versions

Static spec committed to the repo:

```bash
mkdir -p .qa-superteam/contracts
git show <base>:api/openapi.json > .qa-superteam/contracts/base-openapi.json
git show HEAD:api/openapi.json   > .qa-superteam/contracts/head-openapi.json   # committed head
cp api/openapi.json .qa-superteam/contracts/head-openapi.json                  # or: working tree
```

`git show <ref>:<path>` needs the path relative to the repository root. If the file
moved, `git log --follow --name-status -- <path>` finds the old name.

Spec generated from code (FastAPI, NestJS Swagger, springdoc): generate it from each tree.

```bash
mkdir -p .qa-superteam/contracts/base-tree
git archive <base> | tar -x -C .qa-superteam/contracts/base-tree
# FastAPI example: build the app against a throwaway database, dump app.openapi()
(cd .qa-superteam/contracts/base-tree && python3 -c "import json, os, tempfile; from app.main import create_app; print(json.dumps(create_app(os.path.join(tempfile.mkdtemp(), 'spec.db')).openapi(), indent=1))") > .qa-superteam/contracts/base-openapi.json
python3 -c "import json, os, tempfile; from app.main import create_app; print(json.dumps(create_app(os.path.join(tempfile.mkdtemp(), 'spec.db')).openapi(), indent=1))" > .qa-superteam/contracts/head-openapi.json
```

- Use the project interpreter; an import that connects to a real database at import time
  must be pointed at a temporary one (environment variable or factory argument) or not
  run at all.
- If the base tree needs different dependencies than the installed ones, generation may
  fail: record that as BLOCKED rather than diffing a spec generated by the wrong code.
- GraphQL: `git show <base>:schema.graphql`; for code-first schemas print the SDL from
  each tree (`graphql.print_schema`, `printSchema`). Protobuf: tools read the base
  directly from git (below).

## 3. Diff with an installed tool, recorded as an execution

| Contract | Tool (only if installed; never `npx`/`uvx` downloads unasked) | Command through qast |
|---|---|---|
| OpenAPI 3.x | `oasdiff` | `qast exec command --group contract --label "contract-diff openapi" -- oasdiff breaking .qa-superteam/contracts/base-openapi.json .qa-superteam/contracts/head-openapi.json --fail-on ERR` |
| OpenAPI 3.x (no oasdiff) | stdlib script below | `qast exec command --group contract --label "contract-diff openapi" -- python3 .qa-superteam/contracts/openapi_diff.py .qa-superteam/contracts/base-openapi.json .qa-superteam/contracts/head-openapi.json` |
| Protobuf | `buf` | `qast exec command --group contract --label "contract-diff proto" -- buf breaking --against ".git#ref=<base>"` (add `,subdir=proto` when the module is not at the root) |
| GraphQL | `graphql-inspector` (local install) | `qast exec command --group contract --label "contract-diff graphql" -- node_modules/.bin/graphql-inspector diff .qa-superteam/contracts/base.graphql schema.graphql` |
| JSON Schema / event payloads | none needed | `qast exec command --group contract --label "contract-diff events" -- git diff --no-index --exit-code .qa-superteam/contracts/base-event.schema.json schemas/event.schema.json` (records the textual diff; classify each change by hand with the catalogue) |

The `command` adapter records one result from the exit code: non-zero ⇒ FAILED, with the
tool output as hashed evidence. Check `--help` of the installed tool version for the exact
fail flag (`oasdiff` older releases use `--fail-on-diff`). A tool missing ⇒ use the
script or the manual catalogue; say which.

## 4. `openapi_diff.py` (stdlib, OpenAPI 3.0/3.1 JSON, YAML if PyYAML is installed)

Write it to `.qa-superteam/contracts/openapi_diff.py`. It walks operations, parameters,
request bodies and response bodies (nested properties and array items, local `$ref`s),
is direction-aware (request vs response), and exits 1 when anything is BREAKING. It does
not walk `allOf` compositions, discriminators, headers, security schemes, callbacks or
links: review those by hand with the catalogue.

```python
"""Classify changes between two OpenAPI 3.x JSON (or YAML, if PyYAML is installed) documents.

Usage: python3 openapi_diff.py BASE HEAD
Prints BREAKING / POTENTIAL / INFO lines; exit 1 if any BREAKING change, else 0.
"""
import json
import sys

METHODS = ("get", "put", "post", "delete", "patch", "head", "options", "trace")
out = {"BREAKING": [], "POTENTIAL": [], "INFO": []}
# constraint -> "is the second value stricter than the first?"
TIGHTER = {
    "maxLength": lambda old, new: new < old,
    "maximum": lambda old, new: new < old,
    "maxItems": lambda old, new: new < old,
    "minLength": lambda old, new: new > old,
    "minimum": lambda old, new: new > old,
    "minItems": lambda old, new: new > old,
}


def load(path):
    with open(path, encoding="utf-8") as fh:
        text = fh.read()
    if path.endswith((".yaml", ".yml")):
        import yaml  # only needed for YAML specs

        return yaml.safe_load(text)
    return json.loads(text)


def deref(node, root, seen=()):
    while isinstance(node, dict) and "$ref" in node:
        ref = node["$ref"]
        if not ref.startswith("#/") or ref in seen:
            return {}
        seen = (*seen, ref)
        target = root
        for part in ref[2:].split("/"):
            target = target[part.replace("~1", "/").replace("~0", "~")]
        node = target
    return node if isinstance(node, dict) else {}


def types(s, root):
    s = deref(s, root)
    found = set()
    t = s.get("type")
    found.update(t if isinstance(t, list) else [t] if t else [])
    if s.get("nullable"):
        found.add("null")
    for key in ("anyOf", "oneOf"):
        for alt in s.get(key, []):
            found |= types(alt, root)
    return found


def note(level, where, msg):
    out[level].append(f"{level}: {where}: {msg}")


def compare(b, h, broot, hroot, where, direction, depth=0):
    """direction: 'request' (client sends) or 'response' (client receives)."""
    b, h = deref(b, broot), deref(h, hroot)
    if depth > 12 or not b:
        return
    bt, ht = types(b, broot), types(h, hroot)
    if bt and ht and bt != ht:
        widened, narrowed = ht - bt, bt - ht
        if direction == "request" and not narrowed:
            note("INFO", where, f"accepts more types {sorted(bt)} -> {sorted(ht)}")
        elif direction == "response" and not widened:
            note("INFO", where, f"returns fewer types {sorted(bt)} -> {sorted(ht)}")
        else:
            note("BREAKING", where, f"type {sorted(bt)} -> {sorted(ht)}")
    be, he = set(map(json.dumps, b.get("enum", []))), set(map(json.dumps, h.get("enum", [])))
    if be and he:
        if direction == "request" and be - he:
            note("BREAKING", where, f"enum values no longer accepted: {sorted(be - he)}")
        if direction == "response" and he - be:
            note("POTENTIAL", where, f"new enum values returned: {sorted(he - be)} (strict clients may reject)")
    for key, tighter in TIGHTER.items():
        bv, hv = b.get(key), h.get(key)
        if hv is not None and (bv is None or tighter(bv, hv)) and direction == "request":
            note("BREAKING", where, f"{key} tightened {'absent' if bv is None else bv} -> {hv}")
        elif bv is not None and (hv is None or tighter(hv, bv)) and direction == "response":
            note("POTENTIAL", where, f"{key} loosened {bv} -> {'absent' if hv is None else hv} (clients may receive values they reject)")
    for key in ("pattern", "format"):
        if b.get(key) != h.get(key):
            note("POTENTIAL", where, f"{key} changed {b.get(key)!r} -> {h.get(key)!r}")
    bprops, hprops = b.get("properties", {}), h.get("properties", {})
    breq, hreq = set(b.get("required", [])), set(h.get("required", []))
    for name in sorted(set(bprops) | set(hprops)):
        w = f"{where}.{name}"
        if name not in hprops:
            if direction == "response":
                note("BREAKING", w, "field removed from response")
            elif h.get("additionalProperties") is False:
                note("BREAKING", w, "request field removed and additionalProperties is false")
            else:
                note("POTENTIAL", w, "request field removed (server may now ignore or reject it)")
            continue
        if name not in bprops:
            if direction == "request" and name in hreq:
                note("BREAKING", w, "new REQUIRED request field")
            elif direction == "request":
                note("INFO", w, "new optional request field")
            else:
                note("INFO", w, "new response field (safe for tolerant readers)")
            continue
        if direction == "request" and name in hreq and name not in breq:
            note("BREAKING", w, "request field became required")
        if direction == "response" and name in breq and name not in hreq:
            note("BREAKING", w, "response field no longer guaranteed (required -> optional)")
        compare(bprops[name], hprops[name], broot, hroot, w, direction, depth + 1)
    if "items" in b and "items" in h:
        compare(b["items"], h["items"], broot, hroot, f"{where}[]", direction, depth + 1)


def json_schema(container, root):
    content = deref(container, root).get("content", {})
    media = content.get("application/json") or next(iter(content.values()), {})
    return media.get("schema", {})


def params(op, path_item, root):
    found = {}
    for p in [*path_item.get("parameters", []), *op.get("parameters", [])]:
        p = deref(p, root)
        found[(p.get("in"), p.get("name"))] = p
    return found


def main(base_path, head_path):
    base, head = load(base_path), load(head_path)
    bpaths, hpaths = base.get("paths", {}), head.get("paths", {})
    for path in sorted(set(bpaths) | set(hpaths)):
        for method in METHODS:
            bop = (bpaths.get(path) or {}).get(method)
            hop = (hpaths.get(path) or {}).get(method)
            where = f"{method.upper()} {path}"
            if bop and not hop:
                note("BREAKING", where, "operation removed")
                continue
            if hop and not bop:
                note("INFO", where, "new operation")
                continue
            if not bop:
                continue
            if hop.get("deprecated") and not bop.get("deprecated"):
                note("INFO", where, "operation deprecated")
            bp, hp = params(bop, bpaths[path], base), params(hop, hpaths[path], head)
            for key in sorted(set(bp) | set(hp), key=str):
                w = f"{where} param {key[0]}:{key[1]}"
                if key not in hp:
                    note("POTENTIAL", w, "parameter removed")
                elif key not in bp:
                    note("BREAKING" if hp[key].get("required") else "INFO", w, "new " + ("REQUIRED" if hp[key].get("required") else "optional") + " parameter")
                else:
                    if hp[key].get("required") and not bp[key].get("required"):
                        note("BREAKING", w, "parameter became required")
                    compare(bp[key].get("schema", {}), hp[key].get("schema", {}), base, head, w, "request")
            if "requestBody" in bop or "requestBody" in hop:
                hreq_body = deref(hop.get("requestBody", {}), head)
                if hreq_body.get("required") and not deref(bop.get("requestBody", {}), base).get("required"):
                    note("BREAKING", where, "request body became required")
                compare(json_schema(bop.get("requestBody", {}), base), json_schema(hop.get("requestBody", {}), head), base, head, f"{where} request", "request")
            bres, hres = bop.get("responses", {}), hop.get("responses", {})
            for code in sorted(set(bres) | set(hres)):
                w = f"{where} {code}"
                if code not in hres:
                    level = "BREAKING" if code.startswith("2") else "POTENTIAL"
                    note(level, w, "response status removed")
                elif code not in bres:
                    note("POTENTIAL" if code.startswith("2") else "INFO", w, "new response status")
                else:
                    compare(json_schema(bres[code], base), json_schema(hres[code], head), base, head, f"{w} response", "response")
    for level in ("BREAKING", "POTENTIAL", "INFO"):
        print("\n".join(out[level]) or f"{level}: none")
    return 1 if out["BREAKING"] else 0


if __name__ == "__main__":
    if len(sys.argv) != 3:
        sys.exit(__doc__)
    sys.exit(main(sys.argv[1], sys.argv[2]))
```

Read every BREAKING and POTENTIAL line against the catalogue before reporting: the
script classifies mechanically and cannot know, for example, that a removed field was
never populated, or that an enum value is new but only returned to opted-in clients.

## 5. After the diff

- For each BREAKING/POTENTIAL item, search for consumers (`consumer-impact.md`) and decide:
  unintended regression (finding), intended but unannounced (finding: process/versioning),
  intended and versioned with migration notes (record `qast run note --kind decision`
  citing the changelog/version bump; the failed contract check still needs a human to
  accept it at the gate).
- Run implementation-vs-contract tests on HEAD (`contract-testing.md`): a correct-looking
  spec diff means nothing if the implementation does not follow the spec.
